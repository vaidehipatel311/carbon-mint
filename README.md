# Carbon Mint

A web dashboard for managing land owners, parcels, and related operations. Built with React, Redux, MUI, and Firebase.

## Live Demo

**Deployed Website:** [https://your-deployed-url.com](https://your-deployed-url.com)  


## Features

- Land owner CRUD (add/edit)
- File uploads (Aadhar, passbook, leased documents)
- Authentication context
- Dashboard and operator workflows
- Error handling and loading states
- Internationalization support (RTL/LTR)

## Tech Stack

- **Frontend:** React (v18)
- **UI:** Material UI (MUI)
- **State Management:** Redux (with `redux-devtools-extension`)
- **Forms:** Formik
- **Styling:** CSS / custom styles
- **Authentication:** Custom via `AuthProvider`
- **Utilities:** URL polyfill, i18n, Firebase (optional)

## Prerequisites

- Node.js (>=18 recommended)
- npm (comes with Node) or yarn
- Git
